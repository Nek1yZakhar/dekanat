## ⏱️ 1-минутный сценарий сквозной проверки (Экспресс-тур для жюри)

1. **Вход в систему**:
   - Перейдите на [https://153.51.174.89.sslip.io/login](https://153.51.174.89.sslip.io/login) и нажмите кнопку **«Студент 1 (Отличник)»** $\to$ войдите в кабинет.

   - Откройте раздел **«AI-деканат»** (`/ai`) и задайте вопрос: *«Как получить академический отпуск по медицинским показаниям?»* или *«Когда проходят пересдачи?»*.

## 🛠️ Технологический стек

- **Frontend & App Framework**: Next.js 16 (App Router, Turbopack, React 19, TypeScript strict mode).
- **Стилизация & UI**: Tailwind CSS v4, shadcn/ui primitives, дизайн-токены OKLCH, иконки `lucide-react` (Zero-Emoji в B2B интерфейсах).
- **База данных & Auth**: Supabase Postgres 17 (строгий Row Level Security на всех 10 таблицах), Supabase Auth, расширение `vector` (`pgvector`).
- **AI & RAG Pipeline**: Серверный роут с семантическим поиском по фрагментам регламентов, SOCKS5-эгресс к открытым моделям (`google/gemma-4-31b-it:free`, `baidu/ernie-5.5`) и детерминированный оффлайн-фоллбэк с цитированием.
- **Инфраструктура & Продакшен**: Виртуальная машина Yandex Cloud (Ubuntu 24.04, 2 vCPU, 2 ГБ RAM, 10 ГБ SSD, 1.5 ГБ swap), обратный прокси Caddy 2 с автоматическим Let's Encrypt TLS 1.3, multi-stage Docker (non-root `nextjs:nodejs`, RSS ~220 МБ).
- **CI/CD & Автоматизация**: GitHub Actions workflow (`.github/workflows/deploy.yml`) + локальный 1-клик скрипт `pnpm deploy:prod`.

## ⚡ Локальный запуск и разработка

### 1. Требования
- Node.js 20+ (рекомендуется 22+)
- pnpm 9+
- Аккаунт Supabase с расширением `vector`

### 2. Установка зависимостей
```bash
pnpm install
```

### 3. Переменные окружения
Скопируйте шаблон окружения:
```bash
cp .env.example .env.local
```
Укажите в `.env.local` параметры проекта:
- `NEXT_PUBLIC_SUPABASE_URL`
- `NEXT_PUBLIC_SUPABASE_ANON_KEY`
- `SUPABASE_SERVICE_ROLE_KEY` (серверный ключ для миграций и сидирования)
- `AI_API_KEY` (опционально, для обращения к LLM; при отсутствии активен встроенный оффлайн-фоллбэк)

### 4. Накат миграций и сидирование данных
1. Выполните SQL-миграцию `supabase/migrations/0001_init.sql` через SQL Editor в панели Supabase.
2. Запустите генерацию вымышленного академического контура:
```bash
pnpm seed
```

### 5. Запуск локального сервера разработки
```bash
pnpm dev
```
Откройте [http://localhost:3000](http://localhost:3000) в браузере (рекомендуется режим эмуляции мобильного экрана 360–412 px).

## 🚀 Деплой на боевой сервер (1-Click Deploy)

Для доставки изменений на виртуальную машину Yandex Cloud настроен автоматизированный скрипт:
```bash
pnpm deploy:prod
```
Команда запускает `scripts/deploy.ps1`, который:
1. Проверяет чистоту локального дерева Git и отправляет коммиты в репозиторий.
2. Подключается по защищенному SSH-ключу к серверу `153.51.174.89`.
3. Подтягивает актуальный код (`git pull origin main`).
4. Пересобирает и перезапускает Docker-контейнеры Caddy и Next.js standalone за $<45$ секунд без даунтайма.
