# Документация проекта «Цифровой деканат»

Все ключевые архитектурные решения, спецификации и инструкции сгруппированы в файлах:
- [ARCHITECTURE.md](ARCHITECTURE.md) — Схема системы (Mermaid), границы сервисов и журнал архитектурных решений (ADR).
- [STATE.md](STATE.md) — Текущий активный тикет, критерии Done-When и журнал закрытых задач.
- [CHANGELOG.md](CHANGELOG.md) — Хронологический журнал изменений версий.
- [CONTEXT.md](CONTEXT.md) — Контекст домена, вымышленные учётные записи, схема DDL и дорожная карта.
- [SETUP.md](SETUP.md) — Пошаговое руководство оператора: где зарегистрироваться, какие ключи получить, настройка MCP и деплой на Vercel.
- [README.md](../README.md) — Руководство по локальному развёртыванию и запуску.
