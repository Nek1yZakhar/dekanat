## 2. Настройка AI-провайдера (Ассистент деканата)

В системе уже работает оффлайн-фоллбэк (чат отвечает по регламентам даже без API-ключа).
Чтобы включить живые ответы нейросети:
1. Зарегистрируйтесь на [openrouter.ai](https://openrouter.ai) (или используйте OpenAI `sk-...`).
2. В файле `.env.local` укажите:
   ```env
   AI_API_KEY=sk-or-v1-ваш-ключ
   AI_BASE_URL=https://openrouter.ai/api/v1
   AI_MODEL=openai/gpt-4o-mini
   ```

## 3. Деплой сервиса на Vercel (для жюри конкурса)

По условиям конкурса сервис должен быть доступен до 28 ноября 2026 года из России без VPN:
1. Зайдите на [vercel.com](https://vercel.com) через GitHub.
2. Нажмите **Add New... → Project**.
3. Выберите репозиторий `dekanat` и нажмите **Import**.
4. В блоке **Environment Variables** добавьте переменные из вашего `.env.local`:
   - `NEXT_PUBLIC_SUPABASE_URL`
   - `NEXT_PUBLIC_SUPABASE_ANON_KEY`
   - `AI_API_KEY` (если получен)
   - `AI_BASE_URL`
   - `AI_MODEL`
5. Нажмите **Deploy**. Проект опубликуется на быстром HTTPS-домене `*.vercel.app`.
