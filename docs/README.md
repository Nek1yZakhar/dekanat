# Документация проекта «Цифровой деканат»

Все ключевые архитектурные решения, спецификации и инструкции сгруппированы в файлах:
- [ARCHITECTURE.md](ARCHITECTURE.md) — Схема системы (Mermaid), границы слоев платформы и журнал архитектурных решений (ADR-001..005).
- [STATE.md](STATE.md) — Текущий активный тикет, критерии Done-When и журнал закрытых этапов.
- [CHANGELOG.md](CHANGELOG.md) — Хронологический журнал версий и релизов.
- [CONTEXT.md](CONTEXT.md) — Паспорт домена, вымышленные учётные записи, схема базы данных и сводная дорожная карта (включая TICKET-09).
- [SETUP.md](SETUP.md) — Пошаговое руководство оператора: боевой хостинг в Yandex Cloud (Москва), Caddy TLS 1.3, автоматизация деплоя (`pnpm deploy:prod` / CI/CD), MCP `vps-ssh-dekanat` и регламент вывода из эксплуатации.
- [README.md](../README.md) — Главная витрина проекта для жюри конкурса, реквизиты доступа, 1-минутный тур проверки и локальный запуск.
