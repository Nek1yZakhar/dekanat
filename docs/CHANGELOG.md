# Журнал изменений — Цифровой деканат

Все значимые изменения проекта «Цифровой деканат» фиксируются в этом файле.

## [TICKET-01: Базовый каркас, Supabase Cloud и проверка работоспособности] - 11.11.2026

### Добавлено
- **Фундамент проекта**: Next.js 16 (App Router, Turbopack), React 19, строгая типизация TypeScript.
- **Слой оформления**: Tailwind CSS v4, палитра цветов OKLCH, компоненты shadcn/ui, мобильная сетка от 360px.
- **Многоуровневые правила управления (AntiGravity)**: `AGENTS.md`, `.agents/rules/{db,ui,ai,security}.md`.
- **Канонический комплект документации**: `ARCHITECTURE.md`, `STATE.md`, `CONTEXT.md`, `SETUP.md`, `TODO.md`, `README.md`.
- **Облачная база данных Supabase Postgres 17**:
  - Создан проект `dekanat` в регионе `eu-central-1` (Франкфурт), ID: `mwzhtjmnjywvhhyxcdgd`.
  - Включено расширение `pgvector`.
  - Накачена DDL-схема миграции с политиками Row Level Security (RLS) для 10 таблиц.
  - База наполнена сид-данными: 3 группы, 3 тестовые учетные записи, расписание, зачётка с баллами БРС, заявки с историей аудита и 40 статей вымышленных регламентов.
- **Модуль академической аналитики**: `lib/academic.ts` с чистыми функциями расчёта прогресса диплома и раннего выявления академических рисков, покрытыми тестами Vitest.
- **Студенческий мобильный интерфейс**: главный дашборд, расписание на неделю с бейджами изменений, зачётная книжка с симулятором, онлайн-заказ справок с трекингом статуса, регуляторный AI-ассистент.
- **Рабочее место сотрудника деканата**: очередь поступающих заявок с историей действий и сменой статусов («В работу», «Готово», «Отклонить»).
- **Серверный маршрут AI-ассистента**: `/api/ai/chat` с векторным поиском регламентов и детерминированным оффлайн-фоллбэком с обязательным цитированием статей.
- **Конкурсный комплаенс**: сквозной баннер-дисклеймер на всех экранах и строго вымышленные персональные данные.
