## 4. Автоматизация деплоя (Continuous Delivery)

### Вариант А: Локальный 1-клик деплой (`pnpm deploy:prod`)
Из рабочей директории на машине разработчика:
```bash
pnpm deploy:prod
```
Скрипт `scripts/deploy.ps1`:
1. Проверяет чистоту репозитория и пушит коммиты в `origin/main`.
2. Подключается по SSH к `ubuntu@153.51.174.89`.
3. Запускает `scripts/deploy_on_server.sh`: подтягивает изменения (`git pull`), пересобирает Docker-образы и перезапускает контейнеры без даунтайма за $<45$ секунд.

### Вариант Б: Remote CI/CD через GitHub Actions
Файл `.github/workflows/deploy.yml` автоматически запускается при пуше в ветку `main`:
1. Выполняет проверки качества: `pnpm typecheck` и `pnpm test`.
2. При успешном прохождении тестов подключается к ВМ через `appleboy/ssh-action` и обновляет контейнеры.
