# TICKET-09: Вывод инфраструктуры из эксплуатации и защита от списаний (Post-Contest Decommissioning)

## Objective
Плановое, гарантированное отключение и удаление всех облачных ресурсов Yandex Cloud (Compute VM, SSD-диск, статический публичный IPv4) на следующий день после завершения оценки жюри конкурса *MGIMO × AI Challenge* (**29 ноября 2026, 12:00 МСК**) для полного исключения непредвиденных списаний с привязанной карты, архивация финальных логов доступа и перевод проекта в консервацию.

---

## Preconditions
- Окно оценки жюри конкурса официально завершено (28 ноября 2026, 23:59 МСК).
- Итоговые оценки выставлены, конкурсные материалы зафиксированы.
- Доступ разработчика к [Консоли Yandex Cloud](https://console.yandex.cloud/) и Supabase Dashboard.

---

## Scope

### 1. Архивация логов и аналитики посещений жюри
- Снятие финальных логов веб-сервера Caddy и приложения Next.js для фиксации визитов экспертов конкурса:
  ```bash
  ssh -i ~/.ssh/id_ed25519 ubuntu@153.51.174.89 "cd /home/ubuntu/dekanat && docker compose logs --no-color > /tmp/prod_final_audit.log"
  scp -i ~/.ssh/id_ed25519 ubuntu@153.51.174.89:/tmp/prod_final_audit.log docs/audit/
  ```

### 2. Снятие финального дампа базы данных (Supabase)
- Экспорт состояния таблиц и заявок через Supabase CLI или MCP-инструмент `get_logs` / дамп схемы.

### 3. Полное удаление ресурсов в Yandex Cloud (Гарантия 0 ₽)
1. **Остановка и удаление виртуальной машины**:
   - Перейди в раздел **Compute Cloud** $\to$ **Виртуальные машины**.
   - Выбери машину `compute-vm-2-2-10-ssd-1795282646320` (`153.51.174.89`).
   - Нажми **Остановить**, затем **Удалить**.
2. **Критически важно: Удаление дисков (SSD)**:
   - В Yandex Cloud диски продолжают тарифицироваться даже при выключенной ВМ!
   - Перейди в подраздел **Диски** $\to$ убедись, что диск `disk-ubuntu-24-04-lts-...` (10 ГБ) удален. Если остался со статусом `Unattached` — нажми **Удалить**.
3. **Освобождение публичного IP**:
   - Перейди в раздел **Virtual Private Cloud (VPC)** $\to$ **IP-адреса**.
   - Убедись, что адрес `153.51.174.89` освобожден (удален).

### 4. Аудит биллинга и защита карты
- Перейди в раздел **Биллинг** $\to$ **Обзор**.
- Убедись, что:
  1. Баланс равен 0,00 ₽ собственных средств.
  2. Стартовый грант (остаток из 4 000 ₽) не ушел в минус.
  3. Текущее потребление (расход в час) равно **0,00 ₽/час**.

### 5. Консервация локального контура и MCP
- Удалить секцию `vps-ssh-dekanat` из `C:\Users\Admin\.gemini\config\mcp_config.json`.
- Перевести проект Supabase Cloud в паузу (`pause_project`).

---

## Out of scope
- Досрочное удаление сервера до 28 ноября 2026 23:59 МСК (сервер обязан работать непрерывно все дни проверки жюри).

---

## Done-When
1. В консоли Yandex Cloud в разделе Compute Cloud отображается: «У вас пока нет виртуальных машин» и «У вас пока нет дисков».
2. Почасовое начисление средств остановлено (0 ₽/час).
3. С привязанной банковской карты не списано ни одного рубля собственных средств.
4. Логи посещений жюри сохранены в репозитории проекта.
