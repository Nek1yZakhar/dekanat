# Цифровой деканат (Dekanat)

> **Концепт для конкурса MGIMO × AI Challenge. Не является официальным сервисом ИГУ.**

Мобильно-ориентированный прототип цифрового деканата будущего: единое окно для расписания занятий, зачётной книжки, симулятора пути к диплому, подачи справок с трекингом статуса и регуляторного AI-ассистента на базе регламентов университета.

---

## ⚡ Быстрый старт

### 1. Требования
- Node.js 20+ (рекомендуется 22+)
- pnpm 9+
- Аккаунт Supabase (бесплатный тариф)

### 2. Установка зависимостей
```bash
pnpm install
```

### 3. Настройка переменных окружения
Скопируйте пример окружения:
```bash
cp .env.example .env.local
```
Заполните ключи из вашего проекта Supabase в `.env.local`:
- `NEXT_PUBLIC_SUPABASE_URL`
- `NEXT_PUBLIC_SUPABASE_ANON_KEY`
- `SUPABASE_SERVICE_ROLE_KEY` (серверный ключ для сидирования и администрирования)
- `AI_API_KEY` (опционально, для реального LLM-ответа; при отсутствии активен оффлайн-фоллбэк)

### 4. Накат миграций и сидирование базы данных
1. В панели Supabase перейдите в **Database → Extensions** и убедитесь, что включено расширение `vector`.
2. Выполните SQL-миграцию из файла `supabase/migrations/0001_init.sql` через **SQL Editor** в Supabase Dashboard.
3. Запустите сидирование тестовых данных:
```bash
pnpm seed
```

### 5. Запуск в режиме разработки
```bash
pnpm dev
```
Откройте [http://localhost:3000](http://localhost:3000) в браузере (рекомендуется режим эмуляции мобильного экрана 360–412 px).
