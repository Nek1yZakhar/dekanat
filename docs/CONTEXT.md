# Контекст и паспорт домена — Цифровой деканат

## 1. Назначение системы
«Цифровой деканат» — мобильно-ориентированный прототип студенческого портала самообслуживания («деканат будущего»), разработанный для конкурса *MGIMO × AI Challenge* (трек Vibe-Coding, дедлайн: 22.11.2026 23:59 МСК). Портал объединяет разрозненные процессы университета в едином окне:
- Расписание пар и оперативные уведомления о переносах аудиторий или отменах.
- Электронная зачётная книжка, средний балл (GPA) и индикатор риска отчисления «Путь к диплому».
- Онлайн-заказ справок и заявлений со статусом готовности в стиле отслеживания доставки.
- Университетские объявления и точечные оповещения для академических групп.
- Регуляторный AI-ассистент с поиском по вымышленным университетским регламентам (RAG).

## 2. Обязательные требования конкурса (комплаенс)
1. **Сквозной дисклеймер**: На всех страницах закреплен баннер: *«Концепт для конкурса. Не является официальным сервисом ИГУ»*.
2. **Исключительно вымышленные данные**: 100% сгенерированные имена, оценки, номера зачёток и состав преподавателей. Использование реальных персональных данных строго запрещено.
3. **Изоляция данных (RLS)**: Студент не имеет доступа к профилю, оценкам или заявкам другого студента даже при ручной подмене идентификаторов в строке браузера.
4. **Мобильная адаптивность**: Полноценный интерфейс без горизонтального скролла на экранах от 360px.
5. **Доступность из РФ без VPN**: Сервис должен стабильно открываться и работать при оценке жюри без средств обхода блокировок.
