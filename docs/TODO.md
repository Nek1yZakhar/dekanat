## 🎯 Срочные действия оператора (10–15 минут)

### 1. Получить и прописать ключ нейросети (`AI_API_KEY`)
*Сейчас чат отвечает оффлайн по ключевым словам. С ключом он станет полноценной умной LLM.*
- **Рекомендуемый сервис**: [OpenRouter](https://openrouter.ai/) (пополняется криптой и картами, работает из РФ, дает доступ к сотням моделей).
- **Альтернатива**: [ProxyAPI](https://proxyapi.ru/) или ключ OpenAI `sk-...`.
- **Что сделать**:
  1. Скопировать ключ (например, `sk-or-v1-...`).
  2. Открыть локальный файл `.env.local` в корне проекта.
  3. Вставить:
     ```env
     AI_API_KEY=sk-or-v1-ваш-ключ
     AI_BASE_URL=https://openrouter.ai/api/v1
     AI_MODEL=openai/gpt-4o-mini
     ```

---

### 2. Задеплоить проект на Vercel (Бесплатно, 2 минуты)
*Требование конкурса: сервис должен быть доступен круглосуточно по публичной ссылке без VPN.*
- **Что сделать**:
  1. Зайти на [vercel.com](https://vercel.com) и авторизоваться через GitHub.
  2. Нажать **Add New... → Project**.
  3. Найти репозиторий `dekanat` и нажать **Import**.
  4. Раскрыть секцию **Environment Variables** и скопировать туда значения из `.env.local`:
     - `NEXT_PUBLIC_SUPABASE_URL` = `https://mwzhtjmnjywvhhyxcdgd.supabase.co`
     - `NEXT_PUBLIC_SUPABASE_ANON_KEY` = `eyJhbGciOiJIUzI1NiIsInR5cCI6IkpXVCJ9...`
     - `AI_API_KEY` = (ваш ключ)
     - `AI_BASE_URL` = `https://openrouter.ai/api/v1`
     - `AI_MODEL` = `openai/gpt-4o-mini`
  5. Нажать кнопку **Deploy**.
  6. Через 1 минуту Vercel выдаст готовую рабочую ссылку вида `https://dekanat-xxxx.vercel.app`.
